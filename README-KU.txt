SAFAR SHERZAD — بازاڕی کوردستان (وەشانی ئاسان)
1. ZIP بکەرەوە بە Extract All.
2. بچۆ ناو فۆڵدەری SAFAR_SHERZAD_MARKETPLACE_READY.
3. دووجار کرتە لە index.html بکە؛ لە Chrome دەکرێتەوە.
4. بۆ گۆڕینی کۆد، index.html لە Visual Studio Code بکەرەوە.
تایبەتمەندی: گەڕان، پۆل، فلتەری شوێن و نرخ، دڵخوازکردن، زانیاریی ڕیکلام، زیادکردنی ڕیکلامی دیمۆ و پاشەکەوتی localStorage.
گرنگ: ئەمە دیمۆی ناوخۆییە. بۆ ئەوەی ڕیکلامەکان بۆ هەموو کەس پیشان بدرێن، هەژمار و داتابەیس و هۆستینگ ڕێکبخرێن. کۆپی تەواوی FINN.no نییە و کۆدی تایبەتی ئەو سایتە بەکارناهێنێت.
